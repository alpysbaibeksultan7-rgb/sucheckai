# sucheckai
SuCheckAI — портативное устройство и ИИ-платформа для быстрой оценки качества поливной воды и засоления почв прямо в поле. Измеряет TDS, pH, температуру и параметры атмосферы за минуты, сохраняет данные с геометками и помогает строить цифровые карты засоления, чтобы фермеры принимали обоснованные решения без дорогих и долгих лабораторных анализов.
