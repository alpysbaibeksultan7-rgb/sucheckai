# SuCheckAI — архитектура MVP

## Аппаратная часть (по проектной документации)

- ESP32-WROOM DevKit V1 — управление измерениями.
- ADS1115 — аналого-цифровое преобразование.
- pH-датчик и TDS Meter V1.0 — измерения жидких образцов.
- BME280 — температура, влажность и давление окружающего воздуха.
- OLED SSD1306 — отображение показаний на устройстве.
- Аккумулятор 18650, TP4056, MT3608 — система питания.

Схема подключения, точная версия прошивки, калибровка и наличие датчика температуры **воды** должны быть подтверждены реальным аппаратным кодом и испытаниями. BME280 не измеряет температуру воды, если датчик находится в воздухе.

## Проверенный программный сценарий (по сообщению команды)

Ввод показателей в веб-платформу → сохранение измерения → расчёт и пояснение по заданным правилам → цифровой паспорт поля → экспорт отчёта.

Веб-платформа содержит демонстрационную региональную карту риска. Региональная оценка почвы не равна непосредственному измерению TDS поливной воды. Автоматическая передача показаний прибора через Bluetooth пока не подтверждена сквозным тестом.

## Исходный код

Для воспроизведения проекта в репозитории должны быть размещены **настоящие** файлы веб-приложения и, если доступна, прошивка ESP32. Публичная клиентская сборка сайта не тождественна оригинальным исходникам и может не содержать серверной логики, настроек сборки и приватных зависимостей.
